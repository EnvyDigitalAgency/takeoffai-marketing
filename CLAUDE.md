# TakeoffAI Marketing Website

## What this is
Public-facing marketing site for TakeoffAI, served at **takeoffai.com.au**.
The product app lives separately at `app.takeoffai.com.au` (sign-up: `/signup`, login: `/login`).

## Structure
Plain HTML/CSS/JS, no build step. One HTML file per page, all sharing the same stylesheet and script:

| URL        | File            | Purpose |
|------------|-----------------|---------|
| `/`        | `index.html`    | Home: "try it free" and "book a call" side by side, priced-BOQ section, Cal.com booking, pricing summary |
| `/how-it-works` | `how-it-works.html` | Lead endpoint (the link sent to leads): 90-second founder VSL (`assets/vsl.mp4`, autoplays muted with burned-in captions, tap for sound), one primary CTA to the on-page Cal.com calendar, FAQ. Deliberately has no main nav and a single primary CTA; linked from the footer only. `?name=&email=` prefill the calendar |
| `/product` | `product.html`  | Interactive walkthrough (the 4-step tour), features, exports, ROI calculator |
| `/estimating` | `estimating.html` | TakeoffAI Estimating, the done-for-you service (Oct 2026). Warm off-white (#F7F6F2) leads, black for contrast. The job form is two steps in the hero card (Nov 2026): step 1 ("Step 1 of 2 · about 30 seconds"; name, phone, email, job type, "Next: send your drawings →", no terms box) is the lead: CRM row with Stage "New – DFY", info@ email "Estimating job: … (details to follow)", Meta Lead + `estimating_lead` + Google "Estimating – enquiry submitted" fire right there, once. Step 2 (Company (optional), plans link, deadline, contract value, quote software, notes, How heard, required terms box, "Get my tender priced →") posts `form: "details"` with the Lead ID and a signed code, updates that same Leads row ("Job details received" in Notes), sends "Job details: …" to info@, then goes to `/estimating/thanks`, which fires nothing new for this flow. Skipping step 2 is fine: the lead already counted. Both post to `api/estimating-lead.js`; "Book a quick call" opens the same Cal.com 30-min event with notes "Estimating service enquiry" and `metadata[source]=estimating`. Meta pixel events `estimating_lead`, `estimating_call_click`. Hidden `#results` section waits for real results |
| `/estimating/thanks` | `estimating-thanks.html` | Thank-you after the `/estimating` job form (Nov 2026, for Google Ads). noindex, not in the sitemap. The form hands the lead over in sessionStorage (never the URL); the page fires Meta `Lead` (same event ID as the server's Conversions API event), the existing `estimating_lead`, and the Google "Estimating – enquiry submitted" conversion with enhanced conversions, once, then clears it, so refreshes and direct visits count nothing. `?trade=hvac` points the back link at `/estimating/hvac` |
| `/estimating/setup` | `estimating-setup.html` | Client onboarding form for estimating clients (Nov 2026): how they price, suppliers, site loadings, tender-letter details. noindex, not in the nav or sitemap, minimal nav like `/how-it-works`. Shared files:
- `site.css` — design tokens, nav, footer, buttons, sections, cards, FAQ, CTA band. Page-specific CSS goes in that page's own `<style>`.
- `site.js` — nav scroll/active state, mobile menu, FAQ accordion, scroll-in animation, hero-animation play/pause, Meta Pixel `SignupClick` event on any link to the app sign-up.
- `pixel.js` — Meta Pixel init (pixel 1881764475868036, the only one), loaded on every page. Uses `window.TKA_FB_MATCH` for advanced matching when a page sets it (only `/estimating/thanks`).
- `tracking.js` — loaded in every page's `<head>` before `pixel.js`. Keeps UTMs and click IDs (gclid, gbraid, wbraid, fbclid) from the landing URL for 90 days (`TKA.attribution()`), holds the Google tag (**on since 23 Nov 2026**: Google Ads AW-18590661187, conversions "Estimating – enquiry submitted" and "Call booked" with enhanced conversions; contact details are stripped from the page URL Google sees), fires "Call booked" (Google) and Meta `Schedule` on Cal.com popup/inline bookings, and passes UTMs into Cal.com (`TKA.calParams()`). New pages must include it.
- `takeoffai-hero-animation.html` — the animated product demo embedded in an iframe on the home page.
- Video assets live in `assets/` and are committed to git (keep each under ~20 MB: re-encode with ffmpeg, 720p, CRF 23, `-movflags +faststart`). Source cuts of the VSL are in Jonah's Downloads (`takeoffai_vsl_short.mp4` is the 9:16 captioned master).
- `api/estimating-lead.js` — Vercel function behind the estimating form: writes a row to the "TakeoffAI Lead CRM" sheet (Leads tab, Source = "Estimating page", at an explicit row because column A is hidden and the Sheets append API shifts rows right) and emails info@ via Resend. Needs Vercel env vars `GOOGLE_SA_EMAIL`, `GOOGLE_SA_PRIVATE_KEY` (from `../service_account.json`), `CRM_SHEET_ID`, `RESEND_API_KEY` (from `../.env`), optional `LEAD_NOTIFY_EMAIL`. Lead IDs start `web-est-` and Auto Email is written as `manual_contact`, which is what Grokbot's 8:05am cold emails skip on, so estimating leads never get the software emails.
- Ad tracking on the job form (Nov 2026): tender deadline and plans link are optional ("No plans handy? Leave your details and we'll call you."); "How did you hear about us?" (optional) shows only when the visit has no UTM or click ID; hidden fields carry the UTMs, click IDs and `trade` (Electrical / HVAC). The function writes UTM source/medium/campaign/term/content, gclid, gbraid, wbraid, fbclid, How heard and Trade into their own Leads columns **found by header name** (Leads A–L are the Meta sync's, M–X are Grokbot's: never write by position past J); missing headers are added after the last used column. It also sends the Meta Conversions API `Lead` (hashed email/phone/name, deduplicated with the browser by `event_id`) when `META_CAPI_TOKEN` is set; `META_TEST_EVENT_CODE` (Preview only) routes test leads to Events Manager → Test events. A failed ad event never fails the submission.
- The same function also takes the client setup form (`form: "setup"`): it writes a row to the "Client setup" tab (creates it with a header row if missing), adds "Client setup done dd/mm/yyyy" to Notes on the latest Leads row with the same email (and copies that row's Lead ID across), and emails info@ with subject "Client setup: [business]". Only business, name, phone and email are required. No Simpro in the software question; it's free text.
- `vercel.json` — clean-URL routes. Add a route here when adding a page. `sitemap.xml` lists every page.

## Conventions
- **Nav and footer are duplicated verbatim in every page.** When changing a link, change it in all HTML files (a `grep -l 'nav-links'` finds them).
- Cache-bust `site.css` / `site.js` by bumping the `?v=` query in every page's `<link>`/`<script>` when you change them.
- The business is "TakeoffAI (ABN 97 395 522 316)". There is **no Pty Ltd**: never write "TakeoffAI Pty Ltd" (footers say "© 2026 TakeoffAI · ABN 97 395 522 316"; schema publisher/provider name is "TakeoffAI").
- The `/estimating` job form (at step 2) and `/estimating/setup` have a required, unticked "I agree to the Estimating Service Terms" box; step 1 of the job form has none (it is only a contact enquiry). The function rejects step 2 and setup submissions without it and records terms agreed / version / time (Melbourne, to the second): in Notes on the Leads row for jobs, and in the last three columns of the Client setup tab. Both notification emails include them.
- **No Simpro anywhere on the site** (as of 12 Sept 2026, at Simpro's request). All mentions, the `/simpro` page and its route were removed; the copy now talks about a priced bill of quantities exported to Excel/CSV/PDF instead. Don't reintroduce Simpro until Jonah says they're happy for it to appear.
- Facts the copy relies on (verify in the app before changing): free account gives 2,000 credits, no card; commercial take-off = 1,000 credits, residential = 500; Solo $149/mo, Contractor $349/mo, Unlimited $749/mo (coming soon); packs 1,000/$100, 5,000/$450, 15,000/$1,275. Usage proof (Oct 2026, from Jonah): 1,000+ hours saved, 140,000+ symbols counted. No launch date or "since [year]" on the site (Jonah's call). "Australia's first/original" is not on the site either. Jonah is sourcing a customer testimonial to sit beside the 1,000+ stat; don't write one in the meantime.
- Estimating service facts (Jonah, 2 Nov 2026; replaces the 30 Oct "$497" pricing, which must not reappear, nor "$750 starting price" or "per house"): commercial full tender priced by electrical contract value, ex GST (Jonah, 18 Nov 2026, set from real jobs; replaces the 2 Nov six-band list of $595/$750/$1,150/$1,650/$2,250/from $3,000, which must not reappear): under $100K $395, $100K–$300K $595, $300K–$750K $895, over $750K from $1,295 (quoted). The form's job-size bands match these four. Never publish which client jobs the bands were based on. Residential: up to 5 sheets $299, 6–15 sheets $449, larger quoted. Budget estimate about half price, back in 24–48 hours. Membership teaser (4 Nov 2026): "Sending us a few jobs a month? Memberships save around 20%, with priority turnaround and TakeoffAI included." No membership price on the site ($1,690/mo was removed). The page says every estimate is "checked and priced by an experienced estimator" (Jonah, 23–24 Nov 2026): don't claim in-house, in Australia, or never farmed out/offshore. The page uses "outsourced electrical estimating" in the searcher's voice ("outsource your estimating"), never "we outsource". Speed is the lead message (Jonah, 19 Nov 2026): tenders "back in 24–72 hours", always by the deadline and at least 48 hours before close (the 48–72 hour wording is replaced). Proof line: "We estimated a 30-storey apartment building in one day" (no client name), addenda re-priced the same day, RFIs on day 1, allowances not lazy exclusions. "$110K+ a year in salary alone" for an estimator; price and turnaround confirmed "the same business day"; guarantee "back by your deadline or it's free" with the fine print linking to `/estimating/terms`. Don't show yearly deals, payment plans, setup fees or competitor names. No file upload on the form yet, link or email only; the form asks for job size (contract value band or sheet count) and the handler writes it into Notes.
- Two CTAs everywhere, equal weight: "Try it free" → `https://app.takeoffai.com.au/signup` and "Book a call" → `/demo` (on the home page, `#book-call`, which has the Cal.com embed).

## Local preview
```bash
vercel dev        # http://localhost:3000
# or, without routes: python3 -m http.server 8000
```

## Deploy
Push to `main` on GitHub → Vercel auto-deploys within ~30 seconds.
```bash
git add . && git commit -m "your change" && git push
```

## Domain DNS (already configured)
DNS records are set at the registrar pointing to Vercel. Domain settings: Vercel dashboard → Project → Settings → Domains.
